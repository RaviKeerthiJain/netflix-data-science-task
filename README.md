# Netflix Data Science Tasks

Auspify Data Science Internship: Tasks 1-4 on the Netflix titles dataset.

## Tasks
1. **Data Cleaning & Preprocessing**: handled placeholders and duplicates, fixed dates, and created new features.
2. **Exploratory Data Analysis**: content by type, top countries and genres, ratings and trends.
3. **Recommendation System**: content-based recommender using TF-IDF and cosine similarity.
4. **Trend Prediction**: yearly release trends and forecasts to 2025.

## Tools
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

## How to run
1. Install the libraries: `pip install pandas numpy matplotlib seaborn scikit-learn scipy ipykernel`
2. Keep `Dataset.csv` in the same folder as the notebook.
3. Open `Netflix_DS_Tasks_1_to_4.ipynb` and click Run All.

## Output
Charts and the cleaned dataset are saved in the `outputs/` folder.
